# Guess or Go Boom

A rocket-themed word guessing game played in the terminal. Guess the hidden word one letter at a time. Every incorrect guess makes the rocket lose fuel, its fins, etc.  and after six wrong guesses, it goes boom!

## How to Play

- Run the game in your terminal.
- Guess one letter at a time.
- Correct guesses reveal every matching letter in the word.
- You can’t guess the same letter twice.
- The rocket has six stages. Six wrong guesses end the game.
- Guess all the letters before the rocket runs out of fuel to win.

## Requirements

- Python 3
- The `dictionaryy.py` file, which provides the word list used by the game

Make sure `dictionaryy.py` is in the same folder as the game file.

## Run the Game

From the project folder, run:

```bash
python main.py

## Input Rules
Enter one letter at a time. Numbers, blank input, and inputs containing more than one character are rejected. Repeated guesses are also rejected.
